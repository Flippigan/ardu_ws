## Troubleshooting Guide

### Common Issues & Solutions

#### Namespace Conflicts
```bash
# Check for topic conflicts
ros2 topic list | sort | uniq -d
```
**Solution**: Verify each drone interface uses correct namespace

#### Formation Node Communication
```bash
# Verify node connectivity
ros2 node list
ros2 node info /formation_commander
```
**Solution**: Check all nodes are running and publishing/subscribing correctly

#### SITL Performance Issues
```bash
# Monitor system resources (5 SITL instances)
htop
```
